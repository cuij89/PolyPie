Supported file formats

A. Combination table: one Boolean combination per row. Marker columns contain +/- (or 1/0, Y/N); every numeric column is one sample or group.

B. Gate-name columns (FlowJo export): one sample per row, with column names such as CD4/IFNg+TNFa-IL2+ | Freq. of Parent or PD1+/LAG3-/TIGIT+. An optional text column (e.g. Group) can be used to average by group. Rows named Mean / SD are ignored.
